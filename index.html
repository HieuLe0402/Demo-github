Sổ Tay Lệnh Git Tiếng Việt

Tra cứu nhanh toàn bộ câu lệnh Git từ cơ bản đến nâng cao, kèm giải thích chi tiết, cú pháp chính xác và quy trình làm việc chuẩn cho lập trình viên.

Quy trình dữ liệu Git chuẩn
Vùng 1
Working Dir
git add .
Vùng 2
Staging Area
git commit -m
Vùng 3
Local Repo
git push
Vùng 4
Remote Repo
git pull / fetch
Nhấn / để tìm
Hiển thị: 0 lệnh Mẹo: Click vào nút copy để sao chép lệnh ngay lập tức
Các tình huống làm việc thường gặp

1. Đẩy dự án mới lên GitHub

  1. Khởi tạo kho: git init
  2. Thêm file: git add .
  3. Lưu commit: git commit -m "Initial commit"
  4. Liên kết repo: git remote add origin <URL>
  5. Đổi tên nhánh chính: git branch -M main
  6. Đẩy lên GitHub: git push -u origin main

2. Huỷ bỏ thay đổi chưa commit

  1. Hủy thay đổi 1 file: git restore <file>
  2. Bỏ file khỏi Staging: git restore --staged <file>
  3. Hủy toàn bộ thay đổi chưa commit: git reset --hard HEAD

3. Tạm cất code đang làm dở (Stash)

  1. Lưu tạm thay đổi: git stash
  2. Chuyển nhánh khác fix bug: git checkout <branch>
  3. Quay lại nhánh cũ: git checkout -
  4. Lấy lại code đã cất: git stash pop
